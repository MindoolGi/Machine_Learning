# /week7 — 7주차 결정트리 하이퍼 파라미터 퀴즈

## 1. 준비
1. 같은 폴더의 [reference.md](reference.md)를 읽는다. 강의 요약과 문제 은행(정답·해설 포함)이 들어 있다.
2. 프로젝트 루트의 `WEEK7.md`를 읽는다.
   - 없으면 다음 내용으로 만든다:
     ```
     # 7주차 퀴즈 기록 — 결정트리 하이퍼 파라미터

     <!-- 기록 끝 -->
     ```
   - 이미 기록된 문제 ID(`### W7-xx`, `### N-xx`)와 판정을 확인한다.
3. 문제 수: 인자로 숫자가 오면(`/week7 5`) 그 수, 없으면 10문제.

## 2. 출제 규칙
- **한 번에 한 문제만** 내고 사용자의 답을 기다린다.
- 문제 은행에서 아직 안 낸 문제를 우선 고른다. 개념 / 파라미터 매칭 / 기본값 / 코드 빈칸 / 계산(지니·조합 수) / 상황 판단 / O·X 유형이 고르게 섞이게 한다.
- 계산 문제를 새로 만들 때는 정답 계산을 기록 전에 직접 검산한다.
- 이전 기록에서 판정이 X 또는 △인 문제가 있으면 세션마다 2~3개를 다시 낸다(문제 앞에 `(재출제)` 표시).
- 문제 은행을 다 썼으면 reference.md의 강의 요약에서 새 문제를 만들어 `N-01`부터 번호를 붙인다. 강의 내용 범위를 벗어나지 않는다.
- 문제 문장에 정답이 드러나지 않게 쓴다. 객관식은 보기를 섞는다.
- 출력 형식:
  ```
  **[문제 3/10] W7-07 · 파라미터 매칭**
  (문제 본문)
  ```

## 3. 답변 받은 뒤 — 정답은 채팅에 쓰지 않는다
- **정답, 해설, 맞음/틀림 판정을 채팅에 절대 말하지 않는다.** 판정을 짐작할 수 있는 반응("좋아요!", "아쉽네요" 등)도 쓰지 않는다.
- 사용자가 답하면 즉시 `WEEK7.md`에 기록하고, 채팅에는 `기록했습니다 (3/10)` 한 줄과 다음 문제만 쓴다.
- 사용자가 "모르겠다/패스"라고 하면 답변을 `모름`으로, 판정을 X로 기록한다.
- 사용자가 정답을 물으면 "정답과 해설은 WEEK7.md에 있습니다"라고만 안내한다.
- 힌트를 요청하면 정답을 직접 말하지 않는 수준의 힌트 한 줄만 준다(기록에 `힌트 사용` 표시).

## 4. 기록 형식
Edit 도구로 `<!-- 기록 끝 -->` 줄을 아래 블록 + `<!-- 기록 끝 -->`으로 바꿔 파일 끝에 추가한다(마커는 항상 파일 마지막에 하나만 둔다).

```
### W7-07. (문제 요약 제목) — YYYY-MM-DD
- **유형**: 파라미터 매칭
- **문제**: (낸 문제 전문, 보기 포함)
- **내 답변**: (사용자 답 원문 그대로)
- **판정**: O / △ / X
- **정답**: ...
- **해설**: ... (강의 슬라이드 근거, 헷갈리기 쉬운 점)

```
판정 기준: 핵심을 정확히 맞히면 O, 일부만 맞거나 용어가 부정확하면 △, 틀리거나 모름이면 X.

## 5. 세션 마무리
정해진 문제 수를 다 냈거나 사용자가 "그만/종료"라고 하면 `WEEK7.md`에 다음 블록을 추가한다.
```
## 세션 요약 — YYYY-MM-DD
- 맞힌 문제: n / 총 m (△ k개)
- 틀린 문제: W7-xx, W7-yy
- 복습 포인트: (틀린 문제의 핵심 개념 2~4줄)

```
채팅에는 `m문제 완료, 결과와 정답은 WEEK7.md에 기록했습니다.` 한 줄만 쓴다. 점수도 채팅에 말하지 않는다.
