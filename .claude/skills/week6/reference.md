## A. 강의 요약

### 학습 목표
의사결정트리 소개 / 의사결정 트리 개념 / ID3 / 지니계수와 CART 알고리즘 / 의사결정 트리의 장단점

### 의사결정트리 소개
- 데이터에 있는 **규칙을 학습**을 통해 자동으로 찾아내 **트리(Tree) 기반의 분류 규칙**을 만드는 것
- **지도 학습** 모델. 일련의 분류 규칙을 통해 데이터를 **분류·회귀**에 적용. 결정트리, 의사결정나무라고도 함
- **1986년 로스 퀸란(Ross Quinlan)** 발표
- 관측값과 목표값을 연결하는 예측 모델. 여러 결정(Decision)을 통해 **이진 트리** 구성
- '스무고개' 문답처럼 진행 (예: 배고파? → Yes: 돈 많아? → Yes 스테이크 / No 편의점, No: PC방)

### 트리 구조와 노드
- **루트 노드(Root Node)**: 트리가 시작되는 지점(뿌리)
- **부모 노드(Parent Node)**: 어떤 노드 바로 위에 연결된 노드
- **자식 노드(Child Node)**: 어떤 노드 바로 아래에 연결된 노드
- **리프 노드(Leaf Node)**: 자식 노드가 없는 노드, **단말(Terminal) 노드**라고도 함
- **형제 노드(Sibling Node)**: 같은 부모 노드의 자식 노드들
- **내부 노드(Internal Node)**: 루트와 리프 노드를 제외한 노드
- **깊이(Depth)**: 트리의 깊이. 값이 클수록 복잡성이 높아짐
- 예시 트리: F(루트) → B, G / B → A, D / D → C, E / G → I / I → H
  - 루트 F, D의 부모 B, B의 자식 A·D, D의 형제 A, 내부 노드 B·D·G·I, 리프 A·C·E·H, 깊이 3

### 의사결정트리 생성 시 고려사항
- **어떤 기준으로 규칙을 만들어야 가장 효율적인 분류가 될 것인가**가 알고리즘 성능을 크게 좌우
- 규칙이 많다 = 예측을 위한 학습이 잘 된다고 볼 수 있지만 **동시에 복잡하다는 의미**
- 트리 깊이가 깊어질수록 예측 성능이 저하될 가능성이 높음(과적합) → 적절한 값을 찾는 것이 핵심
- **분지(Split, 가지 분할)**: 트리의 가지를 나누는 것. 분지에 의해 데이터 집합이 작은 집합으로 나뉨. 분지에 사용할 데이터 속성을 잘 활용해야 함
- 가장 적은 노드로 높은 성능을 내려면 한 번의 분지 시 **균일하게** 나누어야 함 → 최대한 **동일한 데이터가 많이 포함**되도록(균일도 높음)
- 주요 하이퍼 파라미터 표(교재 '파이썬 머신러닝 완벽 가이드' 인용): max_depth(기본 None), max_features(기본 None, int/float/'sqrt'/'auto'='sqrt'/'log'), min_samples_split(기본 2, 작을수록 과적합↑), min_samples_leaf(리프가 되기 위한 최소 샘플 수, 불균형 데이터는 특정 클래스가 극도로 작을 수 있으므로 작게 설정), max_leaf_nodes(리프 최대 개수) — 자세한 내용은 7주차

### 결정 트리의 기본 아이디어
- 리프 노드가 **가장 섞이지 않은 상태로 완전히 분류**되는 것
- 혼잡도가 높고 균일도가 낮으면 같은 조건에서 판단하는 데 **더 많은 정보가 필요**
- 규칙이 많으면 그만큼 새로운 노드들을 거쳐야 함 → **복잡성(entropy)이 낮도록** 만드는 것
- 예: 부모 [40, 60] → [28, 42] + [12, 18]은 자식 비율이 부모와 같아 **No Improvement** / [40, 0] + [0, 60]은 **Perfect Split**

### 불순도(Impurity)
- 복잡성을 의미. 해당 범주 안에 **서로 다른 데이터가 얼마나 섞여 있는지**의 정도
- 다양한 개체가 섞여 있을수록 불순도 상승 (Very impure → Less impure → Minimum impurity)
- **현재 노드의 불순도에 비해 자식 노드의 불순도가 감소되도록** 분할
- 각 클래스의 분포에 근거해 측정: p(i|d) = 노드 d에서 클래스 i에 속하는 값의 비율 = p(i)
  - 예: Node 1에 red 10, blue 6 → p(red|1) = 10/16 = 0.625, p(blue|1) = 6/16 = 0.375

### ID3 (Iterative Dichotomiser 3)
- 로스 퀸란의 결정트리 알고리즘, 결정트리의 **초창기 모델**
- Dichotomiser = "이분하다"(슬라이드: 프랑스어) → 반복적으로 이분하는 알고리즘
- 정보이론의 **정보량과 엔트로피(Entropy)**로 불순도 계산
- 생성 방법: ① 루트 노드 생성 ② 모든 단말 노드에서 반복 — **정보이득(Information Gain)이 높은 속성**을 선택해 분할 / 노드 데이터가 **동일 클래스이면 종료** / **더 이상 사용할 속성이 없으면 종료**
- 범주형 속성의 값 개수만큼 가지가 나뉨(예제의 날씨는 3갈래)

### 정보량(Information)
- 어떤 사건이 가진 정보의 양. **드물게 발생하는 일일수록 정보량이 큼**
- **I(x) = log₂(1 / p(x))**, p(x)는 사건 x의 발생 확률
- p(x)가 1에 가까우면 정보량 0에 가까움(흔한 사건), 0에 가까우면 정보량이 무한히 커짐(드문 사건)
- 예: p = 0.5 → 1, p = 0.25 → 2

### 엔트로피(Entropy)
- **불순도를 수치적으로 측정**하는 지표, **정보량의 기댓값(평균)**
- **Entropy = Σ −pᵢ·log₂(pᵢ)**. 엔트로피가 높으면 불순도가 높고, 낮으면 불순도가 낮음
- 두 클래스일 때 **0 ≤ E ≤ 1**
- 예: red 10, blue 6 → −(10/16)log₂(10/16) − (6/16)log₂(6/16) ≈ 0.95
- 사건들이 일어날 확률이 비슷할수록 엔트로피가 큼. **두 사건 확률이 반반(0.5, 0.5)일 때 최대(1)** → 어떤 사건이 일어날지 모른다는 **불확실성**이 크면 분류하기 어려움. {0.9, 0.1}이면 약 0.47
- 한 클래스만 있으면 엔트로피 0

### 정보 획득(Information Gain)
- **분할 이전 엔트로피 − 분할 이후 엔트로피** (부모 노드와 자식 노드 간 엔트로피 차이)
- **IG(Parent, Child) = E(Parent) − E(Parent | Child)** (슬라이드 첫 식은 IG(S, A) = IG(S) − IG(S | A)로 표기)
- 분할 이후 엔트로피 E(Parent|A)는 자식 노드 엔트로피의 **가중 평균**(자식 샘플 비율 × 자식 엔트로피)
- 결정 트리는 **정보 획득을 최대화**하는 방향으로 학습. **가장 큰 정보 획득을 가지는 속성**을 선택
- 정보 획득을 최대화하려면 분할 후 **엔트로피 값이 작아야** 함
- 예: E(Parent) = 1, E(Parent|A) = 0.7 → IG 0.3 / E(Parent|B) = 0.3 → IG 0.7 → B 선택

### ID3 생성 예제: 테니스 경기 참가 여부
| 날짜 | 날씨 | 온도 | 습도 | 바람 | 참가 |
|---|---|---|---|---|---|
| D1 | 맑음 | 더움 | 높음 | 약함 | X |
| D2 | 맑음 | 더움 | 높음 | 강함 | X |
| D3 | 흐림 | 더움 | 높음 | 약함 | O |
| D4 | 비 | 포근 | 높음 | 약함 | O |
| D5 | 비 | 서늘 | 정상 | 약함 | O |
| D6 | 비 | 서늘 | 정상 | 강함 | X |
| D7 | 흐림 | 서늘 | 정상 | 강함 | O |
| D8 | 맑음 | 포근 | 높음 | 약함 | X |
| D9 | 맑음 | 서늘 | 정상 | 약함 | O |
| D10 | 비 | 포근 | 정상 | 약함 | O |
| D11 | 맑음 | 포근 | 정상 | 강함 | O |
| D12 | 흐림 | 포근 | 높음 | 강함 | O |
| D13 | 흐림 | 더움 | 정상 | 약함 | O |
| D14 | 비 | 포근 | 높음 | 강함 | X |
- 목표: 참가 여부(O 9, X 5). 조건 속성: 날씨(맑음·비·흐림), 온도(더움·포근·서늘), 습도(높음·정상), 바람(약함·강함)
- **Step 1** 목표 엔트로피: E(경기) = −(9/14)log₂(9/14) − (5/14)log₂(5/14) = **0.94**
- **Step 2** 속성별 분할 후 엔트로피 (가중 평균)
  - 날씨: 맑음 O2·X3, 흐림 O4·X0, 비 O3·X2 → (5/14)(0.971) + (4/14)(0) + (5/14)(0.971) = **0.694**
  - 온도: 더움 O2·X2, 포근 O4·X2, 서늘 O3·X1 → (4/14)(1) + (6/14)(0.918) + (4/14)(0.811) = **0.911**
  - 습도: 높음 O3·X4, 정상 O6·X1 → (7/14)(0.985) + (7/14)(0.592) = **0.789**
  - 바람: 약함 O6·X2, 강함 O3·X3 → (8/14)(0.811) + (6/14)(1) = **0.892**
- **Step 3** 정보획득: 날씨 0.94−0.694 = **0.246**(최대), 온도 0.029, 습도 0.151, 바람 0.048 → **루트 = 날씨**
- **Step 4** 각 리프에서 Step 1~3 반복
  - 맑음(D1, D2, D8, D9, D11, O2·X3): E = 0.971
    - 온도: 더움 O0·X2, 포근 O1·X1, 서늘 O1·X0 → 0.4 → IG 0.571
    - 습도: 높음 O0·X3, 정상 O2·X0 → 0 → **IG 0.971(최대) → 습도로 분할**
    - 바람: 강함 O1·X1, 약함 O1·X2 → 0.951 → IG 0.02
  - 흐림: O4·X0 → 모두 같은 클래스 → **리프 O**
  - 비(D4, D5, D6, D10, D14, O3·X2): 바람 약함은 모두 O, 강함은 모두 X → 바람으로 분할
- **최종 트리**: 날씨 → 맑음: 습도(높음 X / 정상 O), 흐림: O, 비: 바람(강함 X / 약함 O)

### 지니계수(Gini Index)
- 불순도를 측정하는 지표, 데이터의 **통계적 분산 정도**를 정량화한 값
- **G(S) = 1 − Σ pᵢ²** (S: 현재 노드, c: 클래스 개수, pᵢ: 클래스 i가 노드에 속할 확률)
- 엔트로피보다 **계산이 단순**하고 계산 효율성이 높음. 확률이 높을수록 불순도가 빠르게 줄어듦
- 주로 **CART** 알고리즘에서 사용
- 장점: 계산이 간단, 엔트로피와 결과가 유사 / 단점: 정보 획득의 직접적인 해석이 어려움, 확률이 극단적일 때 민감
- 두 클래스일 때 최댓값 0.5(반반), 최솟값 0(한 클래스)

### CART (Classification and Regression Tree)
- 의사결정트리에서 **가장 널리 쓰이는** 알고리즘 (scikit-learn DecisionTreeClassifier도 CART 기반)
- 불순도 측정: **분류 = Gini 계수**, **회귀 = MSE(평균 제곱 오차)**
- 절차: ① 가능한 모든 특성(feature)과 분할 기준(split point)을 탐색 ② 모든 단말 노드에서 반복 — 분할마다 불순도 감소량(지니계수) 계산 / 불순도를 가장 많이 줄이는 분할 기준 선택 / 데이터를 둘로 나눔(**항상 이진 분할**)
- 예제: O 12개, X 11개(총 23개)를 세로선 A 또는 가로선 B로 분할
  - A: A1(O8·X8) G = 1 − (0.5² + 0.5²) = 0.5, A2(O4·X3) G = 1 − ((4/7)² + (3/7)²) ≈ 0.49 → G_A = (16/23)(0.5) + (7/23)(0.49) ≈ **0.497**
  - B: B1(O11·X3) G = 1 − ((11/14)² + (3/14)²) ≈ 0.34, B2(O1·X8) G = 1 − ((1/9)² + (8/9)²) ≈ 0.2 → G_B = (14/23)(0.34) + (9/23)(0.2) ≈ **0.28**
  - 지니계수가 더 낮은(불순도를 더 많이 줄인) **B가 더 좋은 분할 기준**

### 의사결정트리의 장단점
- 장점: 이해하기 쉬운 규칙(**If ~ Then** 형식), 분류 예측에 유용, **데이터 속성의 중요성 비교 가능**, 비교적 빠른 생산 속도
- 단점: **연속형 변수 값을 예측할 때 적당하지 않음**, 트리 모형이 복잡하면 예측력 저하·해석 어려움, **데이터 변형에 민감하여 안정적이지 않음**

A: 분지(Split, 가지 분할) / 한 번의 분지 시 균일하게(균일도가 높게), 즉 최대한 동일한 데이터가 많이 포함되도록 나눠야 함

### W6-07 · 개념
Q: 불순도(Impurity)를 정의하고, 분할 시 불순도를 어떻게 설정해야 하는지 쓰시오.
A: 해당 범주 안에 서로 다른 데이터가 얼마나 섞여 있는지의 정도(복잡성). 다양한 개체가 섞일수록 상승. 현재 노드보다 자식 노드의 불순도가 감소하도록 분할

### W6-08 · 상황 판단
Q: 부모 노드 [40, 60]을 [28, 42]와 [12, 18]로 나눈 분할과 [40, 0]과 [0, 60]으로 나눈 분할을 각각 평가하시오.
A: [28, 42]·[12, 18]은 자식의 클래스 비율(4:6)이 부모와 같아 불순도 감소가 없음 → No Improvement(정보 획득 0) / [40, 0]·[0, 60]은 완전히 분리 → Perfect Split(불순도 0)

### W6-09 · 계산
Q: 노드에 red 10개, blue 6개가 있다. p(red|1), p(blue|1)을 구하시오.
A: 10/16 = 0.625, 6/16 = 0.375

### W6-10 · 개념
Q: ID3의 풀네임과 불순도를 측정하는 방법은?
A: Iterative Dichotomiser 3 / 정보이론의 정보량과 엔트로피(Entropy)로 불순도 계산
해설: Dichotomiser = "이분하다", 반복적으로 이분하는 알고리즘. 결정트리의 초창기 모델.

### W6-11 · 순서
Q: ID3의 결정트리 생성 방법(분할 기준과 종료 조건 2가지)을 쓰시오.
A: 루트 노드 생성 → 모든 단말 노드에서 반복: 정보이득이 가장 높은 속성을 선택해 분할 / 노드의 데이터가 모두 동일 클래스이면 종료 / 더 이상 사용할 수 있는 속성이 없으면 종료

### W6-12 · 공식
Q: 정보량 I(x)의 공식을 쓰고, p(x)가 1에 가까울 때와 0에 가까울 때 정보량은 어떻게 되는지 쓰시오.
A: I(x) = log₂(1/p(x)) / p(x)→1이면 정보량→0(흔한 사건), p(x)→0이면 정보량이 무한히 커짐(드문 사건)
해설: 드물게 발생하는 일일수록 정보량이 큼.

### W6-13 · 계산
Q: 발생 확률이 0.25인 사건과 0.5인 사건의 정보량을 각각 구하시오.
A: log₂(1/0.25) = log₂4 = 2, log₂(1/0.5) = log₂2 = 1

### W6-14 · 공식·개념
Q: 엔트로피의 공식을 쓰고, 엔트로피가 높다는 것의 의미와 정보량과의 관계를 쓰시오.
A: Entropy = Σ −pᵢ·log₂(pᵢ) / 불순도가 높다(불확실성이 크다)는 의미, 엔트로피는 정보량의 기댓값(평균)
해설: 두 클래스일 때 0 ≤ E ≤ 1.

### W6-15 · 계산
Q: red 10개, blue 6개인 노드의 엔트로피를 식으로 쓰고 값을 구하시오(소수 둘째 자리).
A: −(10/16)log₂(10/16) − (6/16)log₂(6/16) ≈ 0.95

### W6-16 · 개념
Q: 두 클래스의 비율이 각각 {0.9, 0.1}, {0.5, 0.5}, {1.0, 0.0}일 때 엔트로피가 가장 큰 경우와 가장 작은 경우는? 최댓값은?
A: 가장 큼 {0.5, 0.5} = 1(최대), 가장 작음 {1.0, 0.0} = 0
해설: 확률이 비슷할수록 엔트로피가 큼. {0.9, 0.1}은 약 0.47.

### W6-17 · 공식
Q: 정보 획득(Information Gain)의 정의와 공식을 쓰고, 결정트리는 정보 획득을 어떻게 이용하는지 쓰시오.
A: 분할 이전 엔트로피와 분할 이후 엔트로피의 차이. IG(Parent, Child) = E(Parent) − E(Parent | Child). 정보 획득을 최대화하는 방향으로 학습하며, 가장 큰 정보 획득을 갖는 속성으로 분할

### W6-18 · 계산
Q: E(Parent) = 1이고, 속성 A로 분할 후 엔트로피가 0.7, 속성 B로 분할 후 엔트로피가 0.3이다. 각 정보 획득과 선택할 속성은?
A: IG_A = 0.3, IG_B = 0.7 → B 선택
해설: 정보 획득을 최대화하려면 분할 후 엔트로피가 작아야 함.

### W6-19 · 계산
Q: 테니스 예제에서 참가(O) 9건, 불참(X) 5건이다. 목표 속성의 엔트로피를 식으로 쓰고 값을 구하시오.
A: E(경기) = −(9/14)log₂(9/14) − (5/14)log₂(5/14) ≈ 0.94

### W6-20 · 계산
Q: 날씨 속성으로 나누면 맑음 O2·X3, 흐림 O4·X0, 비 O3·X2이다. E(경기|날씨)를 구하는 식과 값, 정보 획득을 구하시오. (E(경기) = 0.94, 2:3 비율 엔트로피 = 0.971)
A: (5/14)(0.971) + (4/14)(0) + (5/14)(0.971) ≈ 0.694, IG = 0.94 − 0.694 = 0.246
해설: 흐림은 한 클래스뿐이라 엔트로피 0.

### W6-21 · 계산
Q: 습도로 나누면 높음 O3·X4, 정상 O6·X1이다. E(경기|습도)와 정보 획득은? (3:4 엔트로피 0.985, 6:1 엔트로피 0.592, E(경기) = 0.94)
A: (7/14)(0.985) + (7/14)(0.592) ≈ 0.789, IG = 0.94 − 0.789 = 0.151

Q: 테니스 예제에서 속성별 정보 획득이 날씨 0.246, 온도 0.029, 습도 0.151, 바람 0.048이다. 루트 노드로 선택되는 속성과 이유는?

### W6-26 · 공식·개념
Q: 지니계수의 공식을 쓰고, 엔트로피와 비교한 장점과 단점을 각각 2가지씩 쓰시오.
A: G(S) = 1 − Σpᵢ² / 장점: 계산이 간단(계산 효율성 높음), 엔트로피와 결과가 유사 / 단점: 정보 획득의 직접적인 해석이 어려움, 확률이 극단적일 때 민감하게 작동

### W6-27 · 계산
Q: O 8개, X 8개인 노드와 O 1개, X 8개인 노드의 지니계수를 각각 구하시오.

### W6-28 · 개념
Q: CART의 풀네임과, 분류·회귀에서 각각 사용하는 불순도 측정 방식, 분할 형태의 특징은?

### W6-29 · 순서
Q: CART 알고리즘의 트리 생성 절차를 쓰시오.
A: 가능한 모든 특성과 분할 기준(split point)을 탐색 → 모든 단말 노드에서 반복: 분할마다 불순도 감소량(지니계수) 계산, 불순도를 가장 많이 줄이는 분할 기준 선택, 데이터를 둘로 나눔(이진 분할)

### W6-30 · 계산
Q: 23개 데이터를 기준 A로 나누면 A1(O8·X8, 지니 0.5), A2(O4·X3, 지니 0.49), 기준 B로 나누면 B1(O11·X3, 지니 0.34), B2(O1·X8, 지니 0.2)이다. 각 분할의 가중 지니계수와 더 좋은 분할 기준은?
A: G_A = (16/23)(0.5) + (7/23)(0.49) ≈ 0.497, G_B = (14/23)(0.34) + (9/23)(0.2) ≈ 0.28 → 지니계수가 더 낮은 B가 더 좋은 분할
해설: 분할 후 불순도가 낮을수록(불순도 감소량이 클수록) 좋은 분할.
